# CoW DAO: permissions in place

https://jktranslator.github.io/cow-permissions/

The Zodiac Roles permissions KPK holds as treasury manager on CoW DAO's Safes (Treasury Main on Ethereum, Gnosis,
Arbitrum and Base; Treasury defence on Ethereum and Gnosis), read from each Roles modifier's events on chain: every
allowed function, what it lets the Safe do in plain English, and its conditions. A snapshot, refreshed daily.

`index.html` is generated by [roles-tx-review](https://github.com/JKtranslator/roles-tx-review) (`review/publicpage.py`)
on KPK's review server and pushed here; do not edit it by hand. The page loads nothing from anywhere else. Its
"Ask about these permissions" box sends the question to the review server, which answers from the permissions on the
page only (rate-limited).
